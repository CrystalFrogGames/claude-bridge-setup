# Crystal Frog: Claude bridge setup

Connect your Claude and your Discord bot to the Crystal Frog team's #claude-bridge, with the team skills, in one prompt.

**Paste this into Claude Code:**
```
Clone https://github.com/CrystalFrogGames/claude-bridge-setup into a folder, open it, read its CLAUDE.md, and run the setup steps for me.
```

Your bot token stays on your PC (`~/.tk2_bridge/config.env`). It never goes into a chat or this repo.
